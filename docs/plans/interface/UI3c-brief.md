# UI3c: the stage must never sit under the HUD on a small map

Evidence: weave `sample-world` (`uv run ratatoskr weave --pack sample-world --out /tmp/weave/sample.html`), open it at 1280x900. The sample map is small (about 10x9 tiles). After slices I1+I2 the stage rectangle is the map rectangle, and the HUD frame (health bar, Menu, Messages, speech box, Interact and the four buttons) is drawn INSIDE it: Health sits over the top map tiles, Messages and the speech box over the middle, the button row over the bottom, and the Interact label is clipped. Before I1 the HUD sat in the window corners and nothing overlapped. The visual-regression gate caught it (1.76% drift, gate 0.50%).

Fix: the stage has a minimum size big enough for its HUD frame. When the map is smaller than that minimum, centre the map inside the stage and keep every HUD item in the spare room, never over a map tile. Large maps and phones keep the I1/I2 behaviour. Keep `window.VEFR_STAGE` meaning ("x,y,w,h of the stage, and .map on narrow portrait").

Tests first (frozen before the fix): in `tests/browser/test_stage_containment.py` add a case that weaves the sample world (the fixture helper used by the other cases) and, at the 7 SIZES and the 2 PHONES, asserts that no HUD element's rectangle intersects the map's drawn tile rectangle, and that every HUD element is fully inside the window. It must FAIL on the current branch. Then fix with the smallest change in `web/player/parts/440-the-camera.js` and `020-style.css`, rebuild `uv run python scripts/build_player.py`.

Acceptance: `bash tests/run.sh tests/browser/test_stage_containment.py tests/test_player_build.py tests/test_quiet_ui.py tests/test_declutter.py tests/test_interact.py` passes; `uv run python scripts/build_player.py --check` ok; ruff clean; then weave the sample and run `uv run python scripts/visual_regress.py /tmp/weave/sample.html tests/baselines/packaged-sample.png` and report the drift ratio. Do not update the baseline. Commit nothing outside the repo. Mark anything unmeasured UNKNOWN.
