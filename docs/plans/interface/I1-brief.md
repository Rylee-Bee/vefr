# I1 brief: the stage rectangle and the HUD frame (foreman plan)

Objective: make `tests/browser/test_stage_containment.py` pass (read it first; frozen; never edit it; if it contradicts this brief STOP and report). Context and rules: `docs/plans/interface/PLAN.md`. The player is built from parts: **edit files in `web/player/parts/`, then run `uv run python scripts/build_player.py` and commit the parts AND the regenerated `web/packaged.html`. Never edit `web/packaged.html` by hand** (`tests/test_player_build.py` fails if you do).

One worker (tier `code`). Seams:
1. `web/player/parts/440-the-camera.js`: after every `resize()` and after a region swap, compute the rectangle of the drawn map in viewport CSS pixels: when the whole map fits, it is centred with size `cols*T` by `rows*T`; when it scrolls, it is the canvas rectangle. Clip to the window. Publish `window.VEFR_STAGE = {x, y, w, h}` and set CSS variables `--stage-x/-y/-w/-h` on `#stage`. Re-publish whenever the layout changes (resize, door, fog toggle that changes zoom). Do not change how the map is drawn.
2. `web/player/parts/030-shell.html`: put the HUD blocks (`.hud--tl`, `.hud--tr`), `.toasts`, and the action/Interact/d-pad controls inside one new element `<div class="hud-frame" id="hud-frame">` that is a child of `#stage` (keep ids and the order of elements; screen readers must still hear everything in the same order).
3. `web/player/parts/020-style.css`: `.hud-frame { position:absolute; left:var(--stage-x); top:var(--stage-y); width:var(--stage-w); height:var(--stage-h); pointer-events:none }` and its children `pointer-events:auto` where they were; existing absolute positions (left/right/top/bottom, `max-width`, `.toasts` top offsets, the phone media queries) become relative to the frame. Keep every visual the same otherwise. Before the first publish (no `--stage-*` yet) fall back to `inset:0` so nothing vanishes.
Edge cases to test by hand and mention in the report: a big scrolling map (frame = whole window), the fog-of-war zoom, a door to a smaller region, a phone in landscape.
Do not change behaviour of any pack that does not depend on layout: the weave digest changes (the shell changes) but every other test must still pass. Run `bash tests/run.sh tests/browser/test_stage_containment.py tests/test_player_build.py tests/test_quiet_ui.py tests/test_declutter.py tests/test_interact.py tests/test_skin_apply.py --runxfail` as acceptance (drop a name that does not exist and say so).
Constraints: stdlib; neutral names; no new colours (use existing variables); `git add` only files you changed; never commit PLAN.md or this brief.
