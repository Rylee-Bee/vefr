# W1 brief: walk sheets (foreman plan)

Objective: make `tests/test_walk_sheets.py` pass (read it first; frozen contract, never edit; if a test contradicts this brief STOP and report). Design: `design/pack-art-proposal.md`, "Phase B".

One worker (tier `code`), four seams:
1. Loader (`src/vefr/cli.py`, `_discover_sprites` and its callers): skip `*.sheet.json` as sprites; for `<key>.sheet.json`, read the JSON, resolve `image` beside it with the house path guard (`_inside`, never a path from pack data without it), inline it as a data URI, and attach `{image, frame, fps, directions}` under the sprite key `<key>`.
2. Weave: bake `window.VEFR_SPRITE_SHEETS = {...}` into the player template (`web/packaged.html`), exactly `{}` when the pack has none, so existing packs weave as before.
3. Validator (`maplab`, wired into `maplab.validate` like `sound`/`album` blocks if present, else like the other pack blocks): the rules in the test's docstring, plain sentences naming the sheet file. Read the image size from the PNG/WebP/JPEG header with the stdlib (PNG IHDR is enough for the tests; for webp use a small reader or skip the grid check with a note, never crash).
4. Player (`web/packaged.html`): for a character key that has a sheet, draw the frame instead of the single picture: facing = the last move's direction (hero: down at the start); standing = `idle`; a step = a `walk` frame (advance the cycle once per step, so frames alternate as she walks); settle back to `idle` after the step finishes (the player already settles its hop animation: use that moment); a missing `left` or `right` is the other side drawn mirrored; missing `up` falls back to `down`. Frames are drawn 1.5 tiles tall like the single picture, feet on the tile's bottom, honouring `sprite_scale`. Keep the Phase A hop as it is when there is no sheet; with a sheet use a smaller hop or none (your call, keep `prefers-reduced-motion` honoured). Publish `window.VEFR_HERO_FRAME = {dir, state, frame, mirrored}` ONLY for the hero when the hero has a sheet, updated whenever the pose changes. Apply the same sheets to other characters only if it is a few lines; the tests only pin the hero.
Also: `docs/guides/rulesets.md` gets a short "Walk sheets" section (the three files and the JSON, ten lines); `docs/features.json`: add a feature `walk-sheets` (status `built`, tests `tests/test_walk_sheets.py`, same field shape as its neighbours).
Constraints: stdlib only; neutral names; no network; don't change other tests; acceptance `bash tests/run.sh tests/test_walk_sheets.py tests/test_player_motion.py tests/test_sprite_scale.py tests/test_features.py tests/test_interact.py --runxfail` (if one of those test files does not exist, drop it from the command and say so). `git add` only files you changed; never commit PLAN.md or this brief. Run every worker in the foreground with a long timeout; never background, nohup or a monitor.
Final report: one JSON line `{"done": bool, "files": [...], "escalations": []}`.
