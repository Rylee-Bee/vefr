- `bump(config, state, kind)` -> `{state, grown}`: practice mode only and only for a `kind` some stat uses as its `by`; increments `counts[kind]`; `grown` is a list of `{stat, gain}` for each stat whose total crossed a new step (and is not capped). Otherwise unchanged with `grown: []`.
