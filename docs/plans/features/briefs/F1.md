# F1 — the features module

Read `docs/features.json` (the catalog: do not edit it) and `tests/test_features.py` (the catalog, drift and scan tests) first.

Create `src/vefr/features.py`, standard library only:
- `load_catalog(root=None)` -> list of feature dicts from `<root>/docs/features.json` (`root` defaults to the repo root, found like other modules find it).
- `catalog_errors(root=None)` -> list of plain sentences (empty when sound). Checks: JSON loads and has `features`; every feature has non-empty string `id`, `name`, `what`; `id` unique ("duplicate"); `status` in built / partial / proposed ("status"); `detect` in rules, growth, library, items, enemies, fog, skin, always, none ("detect"); every path in `docs`, `tests` and a non-null `design` exists under root (name the path); a `built` or `partial` feature has at least one `docs` entry and at least one `tests` entry (say "docs" / "tests"); a `proposed` feature has a `design` that exists ("design").
- `scan_pack(pack_dir)` -> list of `{id, used, detail}`, one per catalog feature. `used` is `True`, `False`, or `None` (not detectable from a pack: unknown, not "no"). Rules by `detect`: `always` -> True ("always on"); `none` -> None; `rules` -> the pack `world.json` has a non-empty `rules` list (detail `"N rules"`); `growth` -> a `growth` block (detail `"levels, N levels"` or `"practice"`); `library` -> the pack has books (detail `"N books"`; use the existing `load_library`); `items` -> a non-empty `items` catalog (`"N items"`); `enemies` -> any region contract lists enemies (`"N monsters"`); `fog` -> any region contract declares `fog` (`"N regions"`); `skin` -> `world.json` has `skin` (detail: its name). Use `maplab.load_pack` for the pack and read region contracts through the same loader the validator uses.
- `report(pack_dir=None, root=None)` -> `{"catalog": [...], "pack": None | {"name": <pack dir name>, "uses": scan_pack(...)}}`. Plain JSON types only.

Constraints: do not touch tests, fixtures or the catalog. If a test contradicts this brief, stop and report.
