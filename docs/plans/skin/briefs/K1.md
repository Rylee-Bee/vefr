# K1 — validate a skin, load it, bake it

Read `design/ui-skin.md` ("The idea", "Rules" 1, 5, 6) and `tests/test_skin_validator.py` + `tests/fixtures/make_skin_pack.py` first: they pin every message and the bake format.

A pack's `world.json` may carry `"skin": "skins/<name>"`: a folder INSIDE the pack with a `skin.json` and pictures. Files you may edit: `src/vefr/maplab.py` (add `skin_errors(w, pack_dir)` wired into `validate()` beside `rules_errors`/`grammar_errors`; look at how `rules_errors` and the library check get the pack dir), `src/vefr/world.py` (`load_pack` must pass `skin` through ONLY when declared, and update its docstring; if `load_pack` actually lives in `maplab.py`, edit it there), `src/vefr/cli.py` (in `weave_html`: read the skin and bake it), and in `web/packaged.html` ONLY add the line `window.VEFR_SKIN = {{skin_json}};` next to `window.VEFR_HERO = {{hero_json}};`.

Rules the validator enforces (plain-sentence errors that name the thing): the `skin` path stays inside the pack (no `..`, no absolute path) and is a folder; `skin.json` exists, is JSON, has a non-empty string `name` and `credit`; `parts` keys are only: panel, button, tab, toggle, bar, slot, speech, tooltip, gold-plate, divider, banner, corner, cursor (anything else is named); every picture file a part names (`file`, `hover`, `pressed`, `disabled`, `selected`, `on`, `off`, `frame`, `fill`, `hand`) exists in the skin folder, ends in `.png` or `.webp` (others: say "webp or png"), and is at most 300,000 bytes ("too big"); `slice`, where a part has one, is a whole number >= 1 and at most half of the smaller side of that picture (read PNG width/height from the IHDR chunk with the standard library; for a `.webp` read the size from its header if easy, else skip the half-size check); `ink` colours, if present, are `#RRGGBB`.

The bake: `window.VEFR_SKIN` is the skin as one JSON object: `name`, `credit`, `ink`, and `parts` with every picture file name replaced by a data URI (`data:image/png;base64,...` or `data:image/webp;base64,...`), other fields (`slice`, `hotspot`) kept. A pack with no `skin` bakes the literal `null`. Never an external URL: one offline file.

Constraints: standard library only; no new dependencies; do not touch tests or fixtures. If a test contradicts this brief, stop and report.
