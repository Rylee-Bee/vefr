# D2 — `vefr look` and `vefr probe`

D1 is committed. Read `tests/test_devtools.py` (the look and probe tests) and `tests/test_cli_help.py` first. Both verbs drive the woven single-file player in headless Chromium via Playwright (already in the `test` dependency group). Import Playwright lazily inside the functions; if it or Chromium is missing print a plain message to STDERR naming `uv run playwright install chromium` and return 2.

Add to `src/vefr/devtools.py`:
- `look(html=None, pack=None, out=None, steps='', json_out=False) -> int`: take `html` (a woven file) or weave `pack` to a temp file; open it at 1280x800; click `#ts-enter` (Begin); wait 800 ms; press each comma-separated key in `steps` (250 ms apart); wait 3000 ms (so transient messages have had their chance to fade); screenshot to `out` (default `look.png`); then report every VISIBLE leaf element (has text, not `display:none`/`visibility:hidden`, non-zero box) whose top is in the lower 40% of the viewport OR which sits inside `.toasts`: `{id, cls, tag, y, text}` (text trimmed to 90 chars). `json_out` prints one JSON object `{"screenshot": <path>, "overlay_text": [...]}` to stdout; otherwise print a short human table. This is the tool that finds text standing on top of the map.
- `probe(html=None, pack=None, fire=(), json_out=False) -> int`: open the file, click `#ts-enter`, wait 300 ms, then for each `--fire` spec `event:key=value[,key=value]` (values that look like integers become integers) call `window.fireRule(event, data)` (a global in the player), 50 ms apart, then read `window.VEFR_WHY` (list of `{id, why}`) and `window.VEFR_RULES_STATE.flags`. Output `{"fired": [{"event", "data"}...], "why": [...], "flags": {...}}` as JSON (`json_out`) or a short human list. A spec without `:` or without `key=value` is a usage error: print `use event:key=value` to STDERR and return 2 BEFORE launching a browser.

In `src/vefr/cli.py` add `cmd_look` and `cmd_probe` (thin, like `cmd_find`) and register `look` and `probe` in `vefr_main` (flags exactly as the tests build them: look has `--html`, `--pack`, `--out`, `--steps`, `--json`; probe has `--html`, `--pack`, `--fire` (repeatable, `action='append'`), `--json`), each with `set_defaults(fn=...)`.

Constraints: no new dependencies; do not touch tests or fixtures; keep both functions small. If a test contradicts this brief, stop and report.
