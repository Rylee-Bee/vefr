# Identity terms - a small glossary

Plain-English definitions for the terms vefr uses to describe
itself. New inclusivity work should add to this file rather than
re-explain a concept inline, so the explanations accumulate.

## The always-layer

The four principles the engine commits to regardless of which
world pack is loaded. They're the floor, not a feature list:

- **the loop.** whisper -> keep what's true -> the ledger -> the
  voice compounds. The feedback that makes the engine warmer the
  more you play it.
- **the backups.** Gitea, the durable clone, the NAS bundle. The
  story is never in one place.
- **inclusive-forward.** every screen answers for different
  needs - reading load, target size, contrast over color, motion
  off by default, and when sound arrives, every sound paired
  with a visual event. It is part of the gate, not a follow-up.
- **private until it isn't.** one checkbox, whenever - or never.
  Both are complete endings.

When the engine says something "is part of the always-layer," it
means: this is the contract we hold ourselves to, and a change
that breaks it needs more than a PR.

## Reading row

The set of text-related preferences in the Reading & sound
preferences panel: text size, line spacing, font, contrast,
colorblind-safe palette, motion, focus ring, density. The name
comes from the Fluid Infusion UI Options pattern, where these
controls sit in a single row at the top of the page so they're
reachable in one motion.

## Three Norns / Urd / Verdandi / Skuld

The Norse-coded names for the three columns inside the Reading &
sound panel. Urd (what was) holds the recalled settings and the
device's localStorage. Verdandi (what is) holds the live
controls. Skuld (what will be) holds the live preview. The
metaphor is flavor on top of a normal preferences dialog; the
actual API is English-named.

## Pairing (sound + visual event)

When audio lands, every sound is paired with a visible event -
the bell rings, the page marks the journal entry. The rule is:
never let sound be the only channel for an important moment.

## Luminance over hue

Information hierarchy carried by lightness, not color. Rank and
status are encoded by how bright or dim something is against its
background. A tinted hue (gold, brown-red, blue-gray) is a
secondary cue, never the only one. The principle is migraine-
forward and colorblind-safe by construction.
