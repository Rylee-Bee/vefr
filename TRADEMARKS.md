# Project Identity

VEFR ("the loom-web the Norns weave fate on") is a personal project
by Rylee Hulgan. This page describes how the name is used and how
forks should distinguish themselves.

## The official project

- Canonical source: `https://github.com/Rylee-Bee/vefr`
- Maintainer of record: Rylee Hulgan (the author)
- Official communication channels: GitHub issues and pull requests
  on the canonical repository

Nothing else is "official VEFR" — not a fork, not a re-packaged
distribution, not a hosted service, not a tutorial site. If you
encounter something claiming to be official but not hosted under
the canonical URL above, that claim is incorrect.

## You are welcome to fork

You may fork, modify, and redistribute VEFR under its license (see
`LICENSE`). You may build commercial products on top of VEFR. You
may implement VEFR's contracts, schemas, and pack format in your
own project.

When you do, please use a distinct name for substantially modified
versions and do not imply endorsement by, or affiliation with, the
official project. Examples of acceptable fork naming:

- "VEFR-fork" or "VEFR-something" for a light modification
- A completely different name ("MyRumorEngine") for a substantial
  fork or rewrite

Examples of unacceptable naming:

- "Official VEFR" or "VEFR by <your-org>" for a non-canonical fork
- "VEFR-Pro" / "VEFR-Cloud" / "VEFR-Enterprise" when the offer is
  not from the maintainer of record
- Using the VEFR logo or wordmark to market an unrelated service
