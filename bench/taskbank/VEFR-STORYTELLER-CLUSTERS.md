# VEFR STORYTELLER — DUPLICATE CLUSTERS

## Cluster Methodology

Tasks grouped by: **tested capability**, **world-pack style**, **scenario shape**, **expected behavior overlap**.
Within each cluster, the strongest representative is identified — the task with the clearest test design,
most distinctive scenario, and broadest coverage. Redundant candidates overlap heavily and could be cut.
Suggested retain counts aim for diversity across difficulty levels and risk tiers.

## Reduction Rationale

The suggested retain count aims to:
1. Keep the strongest representative from each tested capability
2. Preserve difficulty diversity (easy/medium/hard) within clusters
3. Preserve risk diversity (low/medium/high)
4. Preserve mode diversity (deterministic/subjective/mixed)
5. Eliminate near-duplicate scenarios that test the same thing with different characters
6. Prioritize tasks with unique failure_labels that aren't covered by retained tasks
