# Memory framing template (Tier 2/3 future use)

When a Tier 2 or Tier 3 storyteller is configured, the harness MAY
prepend a memory-framing block that tells the model how to interpret
the memory slots the packet contains:

- short-term: what just happened
- medium-term: unresolved threads
- long-term: world canon and prior relationship beats

Tier 1 packs (text only) receive the same fields but as plain
sections in the ScenePacket; this template is a placeholder for
future structured-memory packs.
