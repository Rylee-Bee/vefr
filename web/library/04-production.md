Build the real thing in small, finished pieces. Each *milestone* is a
playable build you could show someone. Start with the vertical slice,
then widen.

* * *

A rhythm that works: one goal per sitting, and every sitting ends with
something that works: a build, a map, a page.

Tests keep the old parts working while the new parts arrive.

* * *

**The gate:** every planned feature exists in the game, even the rough
ones.
