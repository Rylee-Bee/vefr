A world feels alive when it notices you.

You read a letter, and the person it was written for says something
new. You beat the last monster on a floor, and a door opens. Nothing
magic is happening. Someone wrote a small rule.

* * *

A rule is one sentence you could read aloud:

"When the hero comes near the keeper, if she has read the letter, then
the keeper says a new line."

It has three parts. The "when" is the thing that happened. The "if" is
a question that must be true. The "then" is what the world does back.

* * *

The "when" is always something you already do. The game starts. You
arrive somewhere. You walk up to a person. You open a chest. You pick
something up. You beat a monster. You buy, you sell. You close a note
you read. The day turns from dusk to dawn.

Because it is only things you already do, you never have to learn a
new action to make the world answer.

* * *

Rules are kept small on purpose. They run in the order they are
written. Each one fires once. And a rule never sets off another rule.

That last part matters. When something surprising happens, there is
exactly one rule to blame, and you can see it. If a rule could start
another, you would chase a long chain to find the cause.

* * *

You can look, too. The menu has a place that answers "Why did that
happen?" Every rule that fired leaves one plain sentence there. It is
the first place to look when the world does something you did not
expect.

A game can have up to forty rules. That is enough to make a whole
story react, one small answer at a time.
