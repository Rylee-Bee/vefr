VEFR is built by helper programs. Each helper works in its own throwaway
copy of the studio: it can read, write and run checks there, and it can
never touch the real studio. When a helper finishes, a person reads the
changes, runs every check, and copies only the good parts back. Nothing
is kept on trust.

* * *

One evening, two helper crews went quiet in the middle of their work.
Each had really finished some pieces - a way for a game to react when
something happens, and one button that does the right thing near you -
but the pieces still lived only in the throwaway copies, and a throwaway
copy is thrown away when it grows old.

* * *

So the copies were found and the pieces copied back before they could be
lost. Then they were checked the same way as always: read the changes,
run the checks, and keep them only when the checks pass. Two old habits
made the rescue possible. Work is not safe until it is copied back, and
a check catches what tired eyes miss.

* * *

The crash left a lesson too, and now there is a habit for it: when a
helper goes quiet, look in its throwaway copy first. The honest story -
what broke and what was fixed - is written down beside the tidy one,
because that is the version the next person can use.
