# web/art/

Studio art for the workshop: resident portraits and expressions (thinking,
happy, sleepy), action poses, room banners and emblems, the studio hero,
the Floor's cutaway illustration, textures, the app icon and the wax seal.

- Source: owner-commissioned art delivered 2026-09-26 (originals, 1024px
  and 2400px PNGs, live in the owner's private media library). These are
  web-sized WebP copies (portraits 320px, banners 1600px, hero 2000px).
- `illustrations/floor-cutaway.webp` was generated 2026-09-26 with the Codex
  CLI's built-in image generation, on the owner's instruction, using the
  studio hero and a room banner as style references; the original and its
  prompt live beside the owner's art originals.
- Engine-neutral: residents and rooms belong to the workshop, not to any
  game pack.
